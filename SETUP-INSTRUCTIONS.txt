🎯 STEP-BY-STEP GITHUB UPLOAD USING WEB INTERFACE

Method 1: Drag & Drop (Easiest)
  1. Go to your GitHub repository
  2. Click "Add file" → "Upload files"
  3. Drag folders from your extracted ZIP
  4. Upload in this order:
     • css/ folder
     • js/ folder
     • images/ folder
     • posts/ folder
     • index.html
     • about.html
     • README.md
     • .gitignore
  5. Commit with message: "Add project files"

Method 2: Click to Add (No drag & drop)
  1. Go to repository
  2. Click "Add file" → "Create new file"
  3. Type: css/styles.css
  4. Copy content of styles.css and paste
  5. Commit
  6. Repeat for each file

Method 3: GitHub Desktop (Recommended for multiple files)
  1. Download GitHub Desktop
  2. Clone your repository
  3. Copy files to cloned folder
  4. Commit in GitHub Desktop
  5. Push to GitHub
